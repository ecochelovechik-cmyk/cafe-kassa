# Центр плова — Касса

Кассовая программа для кафе: столы, доставка, счета, расходы, отчёты.
Работает в браузере, данные хранятся на самом устройстве.

## Как пользоваться

Открыть ссылку на планшете или телефоне и добавить на домашний экран:

- **iPhone (Safari):** Поделиться → «На экран "Домой"»
- **Android (Chrome):** ⋮ → «Установить приложение»

После этого касса запускается как обычное приложение и работает без интернета.

## Важно про данные

Заказы, меню, расходы и история хранятся **в браузере того устройства**, где вы работаете.
На планшете и на телефоне — разные, отдельные базы, они не синхронизируются.

Очистка данных браузера или сброс устройства стирает всё безвозвратно, поэтому
в конце смены: **⚙️ Данные → «Сохранить копию в файл»**.

## Разделы

- **🪑 Столы** — зал и улица, заказы, пречек, оплата, перенос между столами
- **🚚 Доставка** — заказы навынос, оплата курьеру как расход кафе
- **💰 Касса** — приход/расход, покупки, списание блюд, итоги за день/месяц/год, ежемесячные платежи
- **📋 История** — все чеки, возврат в работу и аннулирование
- **📊 Отчёты** — выручка, прибыль, топ блюд, закрытие смены с Z-отчётом
- **🍽️ Меню** — блюда, цены, себестоимость
- **⚙️ Данные** — бэкап, выгрузка в CSV, настройки зала

## Обновление

При изменении `index.html` поднимать версию кэша в `sw.js` (`var CACHE = 'kassa-vN'`),
иначе на устройствах останется старая копия.
